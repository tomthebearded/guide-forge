# Glossary — Shape Jumper

> Terms the guide introduces, defined in plain language. Ordered alphabetically. Each step links here on
> first use of a term. Grows as the ladder introduces concepts.

- **AABB (axis-aligned bounding box)** — a rectangle whose sides line up with the x/y axes (never rotated), used as the collision shape for every object; two AABBs collide when they overlap on both axes. *(Introduced in [Milestone 4](../MILESTONE_4_platforms-and-collision/00_overview.md).)*
- **Acceleration** — how fast a velocity changes per second; gravity is a constant downward acceleration. *(Introduced in [Milestone 3](../MILESTONE_3_gravity-and-jump/00_overview.md).)*
- **AudioContext** — the Web Audio object that represents the audio system; you build sound by connecting nodes inside it, and it must be started from a user gesture. *(Introduced in [Milestone 7](../MILESTONE_7_sound-timer-persistence/00_overview.md).)*
- **Canvas / 2D context** — the `<canvas>` element is a drawing surface; its `getContext('2d')` object is the "pen" you call methods on (`fillRect`, `arc`, …) to paint pixels. *(Introduced in [Milestone 1](../MILESTONE_1_canvas-and-loop/00_overview.md).)*
- **clamp** — forcing a value to stay within a limit: here we cap `dt` at a small maximum so one oversized frame can't teleport or tunnel the player, and we snap the player back onto a surface when it crosses one. *(Introduced in [Milestone 1](../MILESTONE_1_canvas-and-loop/00_overview.md).)*
- **clock** — a running count of seconds since the run started (`clock += dt` each frame); it drives both the gravity-flip schedule and the completion timer. *(Introduced in [Milestone 6](../MILESTONE_6_gravity-twist/00_overview.md).)*
- **Collectible** — an object the player picks up by touching it (here, a coin), which then disappears and changes game state (score). *(Introduced in [Milestone 5](../MILESTONE_5_coins-goal-win/00_overview.md).)*
- **Collision resolution** — after detecting two boxes overlap, moving one out by the smallest distance that separates them, so solids stay solid. *(Introduced in [Milestone 4](../MILESTONE_4_platforms-and-collision/00_overview.md).)*
- **Delta time (`dt`)** — the number of seconds that elapsed since the previous frame; multiplying motion by `dt` makes speed independent of the monitor's refresh rate. *(Introduced in [Milestone 1](../MILESTONE_1_canvas-and-loop/00_overview.md).)*
- **draw()** — the function that paints the current state to the canvas each frame; it reads `Game.state` and changes nothing (all mutation happens in `update`). *(Introduced in [Milestone 2](../MILESTONE_2_player-and-input/00_overview.md).)*
- **edge-triggered (one-shot)** — an action that fires *once* per key press rather than every frame the key is held; we use a "queued" flag the physics step consumes once, so holding Space doesn't machine-gun jumps. *(Introduced in [Milestone 3](../MILESTONE_3_gravity-and-jump/00_overview.md).)*
- **element `id`** — a unique name on an HTML element so JavaScript can find it later with `document.getElementById`; the canvas's `id="game"` is load-bearing. *(Introduced in [Milestone 1](../MILESTONE_1_canvas-and-loop/00_overview.md).)*
- **Entity** — any game object with a position and size (`{x, y, w, h}`): the player, a platform, a coin, the goal. *(Introduced in [Milestone 4](../MILESTONE_4_platforms-and-collision/00_overview.md).)*
- **Frame** — one cycle of the game loop: clear the canvas, update the state, draw everything once. *(Introduced in [Milestone 1](../MILESTONE_1_canvas-and-loop/00_overview.md).)*
- **Game loop** — the repeating "update then draw" cycle that runs many times per second to produce animation. *(Introduced in [Milestone 1](../MILESTONE_1_canvas-and-loop/00_overview.md).)*
- **Game-state machine** — the small set of modes the game can be in (`title` / `playing` / `won`), with rules for moving between them. *(Introduced in [Milestone 7](../MILESTONE_7_sound-timer-persistence/00_overview.md).)*
- **Gravity** — a constant acceleration applied to the player's vertical velocity each frame; its **sign** decides direction (down or, during the twist, up). *(Introduced in [Milestone 3](../MILESTONE_3_gravity-and-jump/00_overview.md).)*
- **Grounded** — a flag that's true when the player is resting on a surface on the gravity-facing side, which is the only time a jump is allowed. *(Introduced in [Milestone 3](../MILESTONE_3_gravity-and-jump/00_overview.md).)*
- **held-key state** — an object recording *which keys are currently down*, updated by `keydown`/`keyup` and read by the game loop every frame, so movement is smooth and continuous rather than one-shot per event. *(Introduced in [Milestone 2](../MILESTONE_2_player-and-input/00_overview.md).)*
- **integrator** — the two-line pattern that turns forces into motion each frame: add acceleration to velocity, then add velocity to position (each scaled by `dt`). *(Introduced in [Milestone 3](../MILESTONE_3_gravity-and-jump/00_overview.md).)*
- **Jump impulse** — a one-time change to the player's vertical velocity (against gravity) that launches it off the ground. *(Introduced in [Milestone 3](../MILESTONE_3_gravity-and-jump/00_overview.md).)*
- **localStorage** — a browser key/value store that keeps strings on the user's machine across page reloads. *(Introduced in [Milestone 7](../MILESTONE_7_sound-timer-persistence/00_overview.md).)*
- **OscillatorNode** — a Web Audio source that produces a pure tone at a given frequency; the building block of our beeps. *(Introduced in [Milestone 7](../MILESTONE_7_sound-timer-persistence/00_overview.md).)*
- **Penetration / overlap** — how far two boxes have sunk into each other on an axis; resolution pushes out by the smaller of the x and y overlaps. *(Introduced in [Milestone 4](../MILESTONE_4_platforms-and-collision/00_overview.md).)*
- **requestAnimationFrame** — the browser API that calls your function right before the next repaint, passing a timestamp; the engine of the game loop. *(Introduced in [Milestone 1](../MILESTONE_1_canvas-and-loop/00_overview.md).)*
- **schedule (the flip schedule)** — instead of flipping gravity on a fixed beat, we compute *when* the next flip is due (`nextFlipAt = clock + a random delay`) and act when the clock reaches it. *(Introduced in [Milestone 6](../MILESTONE_6_gravity-twist/00_overview.md).)*
- **separate-axis resolution** — resolving a collision one axis at a time: move on X and push out of any overlap, then move on Y and push out again — the simplest reliable way to keep solids solid. *(Introduced in [Milestone 4](../MILESTONE_4_platforms-and-collision/00_overview.md).)*
- **Telegraph** — a short visual warning shown before something happens (here, ~1 second before a gravity flip) so the change feels fair, not random-in-a-bad-way. *(Introduced in [Milestone 6](../MILESTONE_6_gravity-twist/00_overview.md).)*
- **title state** — the `'title'` mode shown before play starts: the world is seeded but frozen behind a title overlay until a move key starts the game. *(Introduced in [Milestone 7](../MILESTONE_7_sound-timer-persistence/00_overview.md).)*
- **Velocity** — how fast and in which direction an object moves, in pixels per second, split into horizontal (`vx`) and vertical (`vy`) parts. *(Introduced in [Milestone 3](../MILESTONE_3_gravity-and-jump/00_overview.md).)*
- **win state (`mode: 'won'`)** — the mode the game enters on reaching the goal: `update` freezes so nothing moves, while `draw` keeps painting a victory overlay on top. *(Introduced in [Milestone 5](../MILESTONE_5_coins-goal-win/00_overview.md).)*
- **y-down coordinates** — on a canvas the origin `(0,0)` is the top-left and y **increases downward**, so "fall" means y goes up in value. *(Introduced in [Milestone 1](../MILESTONE_1_canvas-and-loop/00_overview.md).)*
