# M0 · Step 07 of 15 — Generate the "Deep Space Teal" palette
> Nav: [← Add Angular Material](06_add-material.md) · [Overview](00_overview.md) · [Wire the app providers →](08_app-config.md)

> **This step touches two files, committed together:** `src/styles/_theme-colors.scss` (generated by the
> schematic) and `src/styles.scss` (rewritten to `@use` it). They are one unit of work — the palette isn't
> wired until both exist — so they land in one commit.

## Glossary for this step
> **tonal palette** — Material 3 expands one seed color into 13+ numbered tones (0 = black … 100 = white). `mat.theme()` picks the right tones for each role (button fill, text, surface) automatically, in both light and dark schemes.
> **design token** — a named CSS custom property (`--space-void`) holding one design value, so the SCSS *and* the three.js renderer read the same source of truth.

## Why / design
Material 3's theming takes **seed colors** and generates full tonal palettes; `mat.theme()` then maps them onto
every component. We generate a custom palette — the app's dark **"Deep Space Teal"** look — with the official
schematic, then apply it in `styles.scss` and lock the app to the **dark** scheme (it's a globe-in-space
experience). We also declare a set of **design tokens** (plain CSS variables) for the non-Material surfaces —
the globe canvas and heat ramp — so the renderer (M4+) and the SCSS share one palette.

> 📚 New concept — Material 3 custom theming: instead of a canned theme, you feed
> `ng generate @angular/material:theme-color` five seed colors and it emits an `_theme-colors.scss` with the full
> tonal maps. You `@use` those maps in `mat.theme()`. Docs:
> [material.angular.dev/guide/theming](https://material.angular.dev/guide/theming).

## Do this
1. From the project root, generate the palette file:
   ```bash
   ng generate @angular/material:theme-color
   ```
2. Answer the color prompts with these **exact** seed hex values (they define the pastel Deep-Space-Teal look;
   changing them changes the palette). When asked where to write the file, target **`src/styles/`** (filename
   `_theme-colors.scss`):
   - **Primary** → `#9fe0cf`
   - **Secondary** → `#a9d4f0`
   - **Tertiary** → `#c4b5e8`
   - **Neutral** → `#1A2230`
   - **Neutral variant** → `#243042`
   - **"Include high contrast colors?"** → **No** (free choice; we don't ship the high-contrast variant).
3. The schematic writes `src/styles/_theme-colors.scss`. The generated tonal values must match the checkpoint
   below — if your Material version emits slightly different tones, **paste the block below** so the guide stays
   reproducible (it's the authoritative source file).
4. Replace **`src/styles.scss`** with the block below. It `@use`s the generated palettes in `mat.theme()`, locks
   `color-scheme: dark`, and declares the app design tokens. **Do not** delete the tokens — later milestones
   (the globe renderer, the heat ramp, the error toast) read them.

### `src/styles.scss`
```scss
// Angular Material 3 theming — "Deep Space Teal" dark scheme.
// Custom tonal palettes live in `styles/_theme-colors.scss` (generated from seed colors:
// primary #9fe0cf, secondary #a9d4f0, tertiary #c4b5e8, blue-tinted neutrals).
// Regenerate with `ng generate @angular/material:theme-color`.
@use '@angular/material' as mat;
@use './styles/theme-colors' as theme;

html {
  height: 100%;
  @include mat.theme(
    (
      color: (
        primary: theme.$primary-palette,
        tertiary: theme.$tertiary-palette,
      ),
      typography: Roboto,
      density: 0,
    )
  );

  // Lock the app to the dark scheme — this is a globe-in-space experience.
  color-scheme: dark;

  // App-level design tokens for non-Material surfaces (globe canvas, heat ramp).
  // Kept here so the three.js renderer and custom components share one source of truth.
  --space-void: #0d1b2a; // deepest background, behind the globe
  --space-surface: #1b2a3a; // raised panels / sidenav
  --neon-teal: #9fe0cf; // pastel mint — primary accent
  --neon-cyan: #a9d4f0; // pastel sky — secondary accent
  --neon-violet: #c4b5e8; // pastel lavender — tertiary accent
  --flight-marker: #4cc9f0; // now-playing marker icon fill
  // Heat ramp, cold (few/no artists) → hot (most artists). Three soft stops.
  --globe-land-cold: #7fa8c9; // few/no artists — pastel blue (cold)
  --globe-land-mid: #f3e0a0; // mid range — pastel yellow
  --globe-land-hot: #ef9a8a; // most artists — pastel coral (hot)
  --globe-land-empty-stripe: #c2ddf1; // light azure band
  --globe-land-empty-base: #a3aeba; // slate grey gap
  --globe-ocean: #000000; // sphere base
  --glow-shadow: 0 1px 8px rgb(0 0 0 / 25%); // soft neutral elevation
}

body {
  background-color: var(--space-void);
  color: var(--mat-sys-on-surface);
  font: var(--mat-sys-body-medium);
  margin: 0;
  height: 100%;
}

// Slim, theme-aware scrollbars for every scrollable surface.
* {
  scrollbar-width: thin;
  scrollbar-color: color-mix(in srgb, currentColor 28%, transparent) transparent;
}

::-webkit-scrollbar {
  width: 8px;
  height: 8px;
}

::-webkit-scrollbar-track {
  background: transparent;
}

::-webkit-scrollbar-thumb {
  background: color-mix(in srgb, currentColor 28%, transparent);
  border-radius: 4px;
}

::-webkit-scrollbar-thumb:hover {
  background: color-mix(in srgb, currentColor 45%, transparent);
}

// Error toast (MatSnackBar renders in the CDK overlay, so this must be global). Used from M2 onward.
.toast-error {
  --mdc-snackbar-container-color: var(--mat-sys-error-container);
  --mdc-snackbar-supporting-text-color: var(--mat-sys-on-error-container);

    background: rgba(0, 0, 0, 0.32);

  }
```

## If it breaks
- **`Can't find stylesheet to import ./styles/theme-colors`**: the generated file didn't land in `src/styles/`.
  Move it there (Sass resolves `_theme-colors.scss` from the `theme-colors` name) or re-run the schematic with
  that output directory.
- **Background is still white**: `styles.scss` isn't the app's global stylesheet, or the `mat.theme()` include
  is missing — confirm `angular.json` lists `"src/styles.scss"` under `styles` (the scaffold set this).
- **`Undefined variable $primary-palette`**: the `_theme-colors.scss` didn't finish writing both
  `map.merge(...)` exports at the bottom — paste the checkpoint block.
